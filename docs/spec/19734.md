## Diagnosis

### 1. Is `gold_standard_certify()` buggy? — No (CONFIRMED by source read)

Read the live function definition. To certify, a county needs on the **same**
`loop_run_id`:
1. All 10 A-J letters PASS (`ten_pass`).
2. `survived=true` rows in `gold_standard_ultraloop_audit` for **all 10** letters,
   refreshed within 7 days (adversarial-survival evidence).
3. `calendar_parity` guard passed within 7 days (`gold_standard_precert_guards`).
4. `denominator_integrity` guard passed within 7 days.
5. This state must hold for **2 consecutive** evaluated runs (`consecutive_gold >= 2`).
6. Revocation requires 3 consecutive evaluated non-gold runs (N=3 hysteresis, GTM-22H).

This is a correctly-implemented, intentionally strict gate (explicitly designed to
reject ghost-success). It is **not the blocker** — condition 1 alone (10/10 A-J) is
not met by any of the 5 counties today, so conditions 2-5 are moot.

## Root-cause finding on criterion I (confirmed from source)

`pencil_dod_criteria.measures` documents letter I as reading
`v_auction_property_card`'s `zoning_code` column. The **actual**
`pencil_dod_evaluate_county()` SQL (current as of migration
`20260810_gold_standard_shard3_lake_clerk_ssot_cd_recognition.sql`) does not
do that — `card_complete` requires address+geo+value on
`multi_county_auctions` AND `parcel_id`/`tax_account` present in
`v_zoning_gold_standard_card` with non-null `zone_code`, which is sourced
from `public.parcel_zones`. This is a real doc/implementation drift (not
something I changed) that explains why santa_rosa can show 92.2% "card
complete" while every row's `v_auction_property_card.zoning_code` is NULL —
the criterion isn't reading that column at all. Worth a documentation fix at
some point; out of scope to change the function itself this session (M5).

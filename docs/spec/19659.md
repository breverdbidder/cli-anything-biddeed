## Reconciliation query — before/after + confirmed-send match count

```sql
SELECT
  (SELECT count(*) FROM winnerdata.billable_ff_events) AS total_billable_events,
  (SELECT count(*) FROM winnerdata.billable_ff_events bfe
     WHERE winnerdata.has_confirmed_real_send(bfe.source_batch_date)) AS with_confirmed_real_send,
  (SELECT count(*) FROM winnerdata.billable_ff_events bfe
     WHERE NOT winnerdata.has_confirmed_real_send(bfe.source_batch_date)) AS without_confirmed_real_send;
```

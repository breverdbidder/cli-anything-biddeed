## Measurement methodology (L1 only — activation, not output quality)

Per `.claude/rules/evals.md`: "L1 = activation (did it trigger?). L2 = output quality (is it correct?)." This run measures **L1 only**.

- `scripts/eval_runner.py` was invoked standalone against `.claude/skills/cost-discipline/eval.json` to confirm it "still works" per the issue's instruction: exit 0, valid output, but all 25 assertions report `"Unknown check type: "` (`passed: null`, i.e. skipped) — because these skills' `eval.json` files use a **behavioral** format (`assertions[].input` / `.expected`, `type: "binary"`) with no machine-checkable `check` field, unlike the DOCX/JSON-output format `eval_runner.py` was built for. This is correct, expected behavior, not a bug — it's why this workflow does not lean on `eval_runner.py` for pass/fail scoring.
- Per-skill, per-eval.json-having-skill, the workflow takes the first `MAX_CASES_PER_SKILL=3` assertions' own `input` text (the eval author's own trigger scenario) and runs `claude -p "<input>" --output-format stream-json --verbose --include-hook-events --dangerously-skip-permissions`, then parses the transcript for a `tool_use` block named `Skill` whose `input.skill` matches the skill's directory name.
- `outcome = pass` if the skill fired, `fail` if it ran cleanly but didn't fire, `error` if the `claude -p` call itself failed/timed out/produced an unparseable transcript (`skill_invoked` is written `null` in the `error` case — never guessed `true`).
- This is a deliberate, disclosed cap: only 8 of 50 skills have an `eval.json`; those 8 get ≤3 cases each (≤24 `claude -p` invocations total), well under the 15-skill `NO_READING` cap. No case reduction was silently applied beyond this documented `MAX_CASES_PER_SKILL` cap.
- L2 (does the *output* match `expected`) is **not** measured this run — these `eval.json` files don't carry machine-checkable assertions, and grading behavioral correctness would require an LLM judge, which is outside this issue's stated scope ("this run measures, it does not improve").

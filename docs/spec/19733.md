### Root cause — C is the same fleet-wide canon ceiling diagnosed on #19694 yesterday
`pencil_dod_evaluate_county`'s C formula (`supabase/migrations/20260810_gold_standard_shard3_lake_clerk_ssot_cd_recognition.sql` lines ~50-52) counts `CLERK_SSOT_CANCELLED` rows in the denominator (`auctions_total`) but never admits them to the numerator (`matched_clean`). Any county whose real-world cancellation/redemption rate exceeds the ~5% slack in the 95% threshold is structurally capped forever, independent of data quality. This is now independently confirmed in st_lucie and union, on top of the 8 counties already documented in `GOLD_STANDARD_C_STRUCTURAL_BLOCK_CROSS_COUNTY_FINDING_20260827.md` and the identical #19694 diagnosis (`decision_log` id 3041) posted less than 24h earlier for wakulla/suwannee.

**Verified arithmetic if `CLERK_SSOT_CANCELLED` were excluded from C's denominator:**
- st_lucie: 197 / (251-51) = 197/200 = **98.5% → PASS**, which alone would make st_lucie 10/10.
- union: 3 / (4-1) = 3/3 = **100% → PASS** (union would still need `I` fixed to reach 10/10; `J` is gated on `I`).

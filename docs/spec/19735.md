## Root cause (VERIFIED)

Both manatee and nassau are **9/10** live — A, B, D, E, F, G, H, I, J all PASS. The sole blocker is
letter **C (parity_clean)**:

| county | C metric (actual) | matched_clean | auctions_total | matched_any (D's numerator) | C ceiling if canon flips |
|---|---|---|---|---|---|
| manatee | 91.5% FAIL | 161 | 176 | 175 | 99.4% |
| nassau | 94.6% FAIL | 53 | 56 | 54 | 96.4% |

`pencil_dod_evaluate_county`'s canon deliberately excludes `CLERK_SSOT_CANCELLED` rows (genuinely
cancelled/redeemed, clerk-verified) from C's numerator while including them in D's. In both
counties, **100% of the gap between C and D is exactly this excluded class**:
- manatee: 175−161 = 14 rows, all `CLERK_SSOT_CANCELLED`; the 1 remaining point (176−175) is a
  genuinely open row, insufficient alone to reach 95% even if resolved.
- nassau: 54−53 = 1 row, `CLERK_SSOT_CANCELLED`, reconfirmed live **today** by this same shard's
  own engineer session (dispatch `b556ca84`, `parity_source` tag
  `nassau_clerk_tax_deed:redeemed_reconfirmed_20260902_shard4_b556ca84`); the remaining 2 rows
  (56−54) are `PHANTOM_NOT_ON_CLERK`, reconfirmed live yesterday (dispatch `6284f4fc`) as
  genuinely absent from the clerk's public record.

This is not a per-county data bug — it is the exact, already-escalated, still-undecided canon
question tracked on **issue #19617** ("Gold Standard letter C structurally caps 9+ counties — pick
Option A/B/C"), open since 2026-08-27, escalated 3 times (#19606, #19635, #19655) with zero owner
response. This session is the first to show that resolving #19617 toward Option A or B would flip
**both** manatee and nassau C from FAIL to PASS immediately, with zero further data-collection or
engineering work.

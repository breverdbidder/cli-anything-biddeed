## What was built

**cli-anything-biddeed (this repo), branch `fix/20067-gseo-parity`, PR #20071:**
- `src/worker.js` `buildCountiesIndex()` — meta description 175 → 137 chars.
- `src/worker.js` county page template (`buildCountyPage()` output, shared by all 67 `/county/:slug` pages) — the `#bd-fallback` div's `<h1>` (display:none, but still counted by `querySelectorAll`) downgraded to `<p>`. The `<noscript>` copy's `<h1>` was left as-is: browsers with scripting enabled never parse `<noscript>` contents into the DOM, so it was never counted by the harness's `querySelectorAll('h1')` in the first place.
- `src/worker.js` `BUY_REPORT_HTML` — the second and third wizard-step headings (`Pick your auction`, `One SIGNAL$ Property Report — $25`) downgraded `<h1>` → `<h2>` with a matching CSS rule added (`h1,h2{...}`, `html[data-theme=light] h1,h2{...}`); the first step's `<h1>Pick your county</h1>` (default-visible) stays `<h1>`.
- `src/worker.js` `s5Page()` (the `/report/:mca_id` SIGNAL$ report renderer, used for both the public sample report and every real paid report) — added a generated `<meta name="description">` (address + county, capped 155 chars) and changed the subject-address `<div class="rpt-addr-main">` to `<h1 class="rpt-addr-main">`.

**biddeed-web, branch `fix/20067-gseo-parity`, PR #49 (breverdbidder/biddeed-web):**
- `app/layout.tsx` — added `metadataBase: new URL('https://biddeed.ai')` (root, so every route's relative `alternates.canonical` resolves to an absolute URL — none did before this).
- `app/page.tsx` — `alternates.canonical: '/'`; meta description 179 → 153 chars.
- `app/radar/page.tsx` — `alternates.canonical: '/radar'`. Static export (not `generateMetadata`), so this single change covers `/radar`, `/radar?view=calendar`, `/radar?view=map` alike.
- `app/discover/page.tsx` — `alternates.canonical: '/discover'`.
- `app/sign-in/[[...sign-in]]/page.tsx`, `app/sign-up/[[...sign-up]]/page.tsx` — `alternates.canonical` + `robots: { index: false, follow: false }`.
- `/auctions` — no code change. It is not a route in biddeed-web (the Worker owns it); confirmed live that unauthenticated `GET /auctions` 302-redirects to `/radar`, Playwright follows redirects, so the harness's `/auctions` row was actually rendering `/radar`'s HTML the whole time. Fixed automatically by the `/radar` change.

No migrations, no RPCs/views touched.

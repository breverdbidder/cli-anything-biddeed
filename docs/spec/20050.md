## What was built

### `scripts/or_adapters/landmark.py` — Landmark Web (Pioneer Technology Group / Catalis) adapter
Reuses `classify_docs()` / `already_exists()` / `tier1_rows()` / `write_tier1_results()` / `sb_get` / `sb_insert` from `pre_auction_lien_harvest.py` unmodified (same pattern as `scripts/highlands_owner_name_lien_harvest.py`) — only the search transport is Landmark-specific.

**Platform reality, live-verified this session (not assumed from the issue's premise):**
- Landmark Web deployments run Cloudflare or Akamai bot-management in front of a classic ASP.NET MVC + jQuery/DataTables app. A plain `httpx`/`urllib` client gets 403'd on every disclaimer POST regardless of headers (confirmed against `or.martinclerk.com` across 6 separate attempts with progressively more complete browser-like headers — all 403, with escalating collateral blocking of unrelated resources as attempts continued). A real Chromium session (Playwright) that executes the site's own disclaimer/reCAPTCHA JS passes cleanly — this is standard headless-browser automation of a public government search form, not captcha-solving: no interactive challenge was ever presented to or solved by this script; Google reCAPTCHA's invisible v2 token is obtained by the page's own JS during normal navigation, the same as any real visitor's browser does transparently.
- Landmark Web's generic client code (`index.js`) ships a "Case Number Search" path, but whether a county's clerk actually **enables** that nav tab is a per-deployment admin choice, not a fixed platform capability. Live-verified: Bay/Palm Beach/Citrus/Flagler expose it; Martin/Okeechobee do not (name/document/book-page/consideration/record-date/instrument-number/legal only). Landmark Web is fundamentally a **land recording index** (by name/party/document-type), not a court docket index — counties without Case Number Search have no working harvest path in this adapter without an external owner/defendant-name source, which does not exist for these auctions (same disclosed gap as `pre_auction_lien_harvest.py`'s santa_rosa/brevard name-search sweep).
- Response schema (`GetSearchResults`, DataTables server-side JSON) is column-indexed by string keys (`"0".."26"`), not named fields — `_normalize_row()` maps the verified column layout (confirmed against 3 real Bay County instruments: LIS PENDENS/JUDGMENT/ORDER, real book/page/instrument numbers) to the same field names `classify_docs()`/`tier1_rows()` already expect from AcclaimWeb.
- Dates are `MM/DD/YYYY`; converted to `YYYY/MM/DD` before handing to the shared classifier (same reasoning as `pre_auction_lien_harvest.py`'s `normalize_brevard_docs()` — the shared function's senior/junior priority comparison is a lexical string compare that assumes that ordering).

### `scripts/or_adapters/benchmark.py` — documented non-finding, not speculative code
Live-checked the one FL "Benchmark"-branded URL found this session (`apps.stjohnsclerk.com/Benchmark/Home.aspx/Search`, HTTP 200, no login/paywall/captcha): its case-type dropdown is exclusively **court docket** categories (Criminal Felony, Domestic Relations, Probate, Guardianship, Civil Traffic, ...), not a recorded-instrument/document-type search. Independent research confirmed Benchmark and Landmark Web are both Pioneer Technology Group/Catalis products but serve different jobs: **Benchmark = court case management**, **Landmark Web = Official Records/recording**. St. Johns's actual Official Records Search (confirmed via the clerk's own nav menu text) is the separate `apps.stjohnsclerk.com/Landmark` app.

**No FL county was found this session running Benchmark for Official Records / recorded-instrument search — because that product does not do that job.** `benchmark.py` documents this finding and exits with a clear `BLOCKED` message rather than containing speculative scraping code against a product with no real target (K2: no code for scenarios that can't happen; Honesty Protocol: no convincing-looking but untestable code). If a genuine counter-example ever surfaces, the file's docstring says exactly what contract to follow (mirror `landmark.py`).

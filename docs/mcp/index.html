Get an API key at biddeed.ai/dashboard.

Streamable HTTP (Claude web/connectors, remote clients)

URL: https://biddeed.ai/api/mcp
Authorization: Bearer bd_live_xxx   (or a WorkOS OAuth access token)

The server speaks MCP over Streamable HTTP (single /mcp POST endpoint, no legacy SSE transport). Unauthenticated requests receive 401 with a WWW-Authenticate header pointing at /.well-known/oauth-protected-resource per RFC 9728, so OAuth-aware clients can discover the WorkOS AuthKit authorization server automatically.

Authentication

MethodHeaderNotes
API keyAuthorization: Bearer bd_live_xxxIssued per customer; tiered (free / investor / pro / proplus / enterprise)
OAuth 2.1 + PKCEAuthorization: Bearer <WorkOS access token>WorkOS AuthKit is the authorization server. BidDeed MCP is a resource server only — it never issues tokens, only validates them (JWKS + exp/nbf).

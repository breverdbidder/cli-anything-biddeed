Response times

We aim to respond to support email within 1 business day. Auth/billing-blocking issues (invalid key, tier gate errors) are prioritized. For CERT-required tools (predict_auction_outcome) that reject with CERT_REQUIRED, this is expected behavior — see the error message for the exact letter-count gap.

Status

Reachability check: GET https://biddeed.ai/api/mcp — a 401 response (with a WWW-Authenticate header) means the server is up and awaiting credentials; that's expected without a key. Transport: Streamable HTTP.

## Local development

```bash
cd sites/__SLUG_PLACEHOLDER__-web
npm ci
npm run dev        # Astro dev server, pages only -- functions/api/* is NOT served
```

To exercise `functions/api/*.ts` locally (the actual deploy artifact), use
Wrangler's Pages dev server against a built `dist/`:

```bash
npm run build
cp .dev.vars.example .dev.vars   # fill in real values, never commit .dev.vars
npx wrangler pages dev dist --port 8788
```

## Design bar / audit

```bash
npm run build && npm run preview -- --port 4321 &
npm run audit
```

Checks every page (home, get-a-quote, one per `lines_of_business` entry,
about, client-service) at 320/393/768/1440px for horizontal overflow and
console/page JS errors. Requires Playwright's Chromium browser
(`npx playwright install chromium` once).

## Deploy

```bash
npm run build
npx wrangler pages deploy dist --project-name=__SLUG_PLACEHOLDER__-web
```

Or connect this directory (`sites/__SLUG_PLACEHOLDER__-web`) as the Cloudflare
Pages project root via Git integration. See the top-level template README for
the environment variables this site needs.
